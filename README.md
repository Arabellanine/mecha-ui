## 🛠 Core Arsenal

- **Zero Runtime Dependencies:** Pure semantic HTML5, pure CSS variables, zero framework bloat.
- **Avionics Typography Scale:** Calibrated hierarchy leveraging `Space Grotesk` and `JetBrains Mono`.
- **Dynamic Web Audio Synthesizer:** Tactile clicks, frequency sweeps, and acoustic feedback synthesized natively via Web Audio API.
- **CRT & Telemetry Effects:** Real-time CRT scanlines, flicker shaders, and multi-segment telemetry readouts.
- **Universal Status Modules:** Swappable chamfered indicators (`// ONGOING`, `// UNDER CONSTRUCTION`, `// DEPLOYED v1.0`).

## 📦 Quick Start

### 1. Direct CSS Integration
Drop the standalone CSS bundle into your project:

```html
<link rel="stylesheet" href="https://arabellanine.github.io/mecha-ui/mecha-ui.css">
```

### 2. Standalone Status Module
For micro-indicators and portfolio headers:

```html
<link rel="stylesheet" href="https://arabellanine.github.io/mecha-ui/snippets/mecha-status.css">

<div class="mecha-status-module status-deployed">
  <span>// DEPLOYED v1.0</span>
</div>
```

### 3. Obsidian Terminal Snippet
To arm your Obsidian vault with brutalist monospace styling:
Copy `snippets/mecha-terminal.css` into your `.obsidian/snippets/` directory and enable in Settings > Appearance.
